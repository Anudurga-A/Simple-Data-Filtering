# Simple Data Filtering

## Overview

This project demonstrates simple data filtering using Python. A collection of student records is created using a list of dictionaries, and students are filtered based on different conditions such as marks, age, and department.

## Objective

The main objective of this task is to understand how conditions can be used to filter structured data in Python.

## Tools Used

- Python
- Jupyter Notebook

## Student Records

Each student record contains:

- Name
- Age
- Marks
- Department

## Filtering Operations

The project performs filtering using the following conditions:

1. Students with marks greater than 80
2. Students with age 22 or above
3. Students belonging to the MCA department
4. Students satisfying multiple conditions

## Key Concepts

- Python Lists
- Dictionaries
- Conditional Statements
- Data Filtering
- Multiple Conditions

## Output

The program displays the student records that satisfy the specified filtering conditions.

## Conclusion

This task provides a basic understanding of filtering structured student data using Python conditional statements. It helps in learning how specific records can be selected based on different criteria.
